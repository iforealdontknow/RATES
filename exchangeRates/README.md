# Conversor de Monedas

## Estudiante
Fernando David Ponce Agüero

## Descripción
Aplicación web para convertir dólares estadounidenses a lempiras hondureños utilizando tasas de cambio en tiempo real desde una API externa.

## Cómo ejecutar el proyecto

### Instalación
```bash
npm install
```

### Desarrollo
```bash
npm run dev
```
